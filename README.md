# Financial Sales Dashboard - Power BI

## Project Overview

This project presents an interactive Financial Sales Dashboard developed using Power BI.

The dashboard provides insights into sales performance, profit trends, product performance, and regional business analysis through interactive visualizations.

---

## Objectives

- Analyze financial sales data
- Track key business KPIs
- Monitor profit trends
- Compare yearly performance
- Visualize country-wise sales distribution
- Enable dynamic filtering and exploration

---

## Dashboard Features

### KPI Cards
- Total Products
- Units Sold
- Total Profit
- Operating Expenses

### Sales Analysis
- Country vs Product Sales Comparison

### Profit Analysis
- Year-wise Profit Distribution
- Monthly Profit Trend Analysis

### Geographic Analysis
- Interactive Map Visualization

### Interactive Filters
- Product Filter
- Segment Filter
- Year Filter
